Web Guardias — Preparación física (prototipo)

Sitio web sobre preparación física de opositores a Guardia Civil. Contiene secciones de servicios, testimonios y un formulario que usa EmailJS.

Estructura principal:
- index.html — página principal
- styles.css — estilos
- script.js — lógica cliente (carruseles, formulario)
- data.js — datos (testimonios, vídeos)
- imagenes/ — imágenes públicas




Formulario con --> EMAILJS:
- El formulario usa EmailJS para notificar al propietario y enviar una respuesta automática al usuario.
- Las claves/IDs están en script.js bajo CONFIG.emailjs. No subir claves privadas al repo.
